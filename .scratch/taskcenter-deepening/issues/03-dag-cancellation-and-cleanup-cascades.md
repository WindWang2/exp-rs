# 03 — Recursive DAG Task Cancellation & Cleanup Cascades

**What to build:** Implement recursive cancellation and cleanup cascades for parent-child task DAGs. Canceling a root task cleanly cancels all queued and running child tasks without leaking temporary files or worker threads.

**Blocked by:** 01 — Asynchronous Event-Driven Task Dispatching

**Status:** ready-for-agent

- [ ] Canceling a parent task recursively marks dependent queued child tasks as Canceled
- [ ] Running child tasks receive immediate interrupt signals and terminate gracefully
- [ ] Temporary files and intermediate asset outputs generated by canceled tasks are removed
- [ ] Unit tests verify recursive DAG cancellation and zero dangling task states
