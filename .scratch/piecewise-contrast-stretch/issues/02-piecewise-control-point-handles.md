# 02 — Piecewise Control Point Handles on Histogram Canvas

**Type:** wayfinder:prototype

## Question

How should piecewise linear control points $(x_i, y_i)$ be rendered as interactive circular handles on `HistogramWidget`, supporting double-click to add, drag-to-move, and right-click to delete?

## Blocked by

01 — Real Data Range Statistics & Axis Scaling

**Status:** closed

### Resolution
- Rendered piecewise control points $(x_i, y_i)$ as interactive circular node handles ($\bigcirc$) on `HistogramWidget`.
- Supported left-click drag, double-click to add point, right-click to delete point.
- Documented in [0008-real-data-range-and-piecewise-linear-stretch.md](../../docs/adr/0008-real-data-range-and-piecewise-linear-stretch.md).
