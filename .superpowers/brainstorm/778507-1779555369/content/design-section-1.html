Section 1: Modular Display Architecture

Unified framework for extensible data visualization

Proposed Directory Structure (engine/core/display/)
  • base/: Abstract interfaces (MapLayer, DataProvider, FeatureRenderer)
  • raster/: RasterLayer, GDALProvider
  • vector/: VectorLayer, OGRProvider, SingleSymbolRenderer
  • canvas/: MapSettings (snapshot), MapRendererJob (worker)

Design Principles

  • Decoupling: Layers don't know about file formats (Providers do).
  • Immutability: Rendering happens via a MapSettings snapshot, ensuring background threads never touch "live" GUI objects.
  • Extensibility: Adding a new data source (e.g., GeoJSON) only requires a new Provider.
