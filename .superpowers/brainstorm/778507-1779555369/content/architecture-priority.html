Unified Display Architecture

Comparing current simple canvas with proposed QGIS-style modular framework

Current: Monolithic Canvas

MapCanvas (QWidget)

Directly handles:

  • File Loading
  • Reprojection
  • Rendering (Raster/Vector)
  • Interaction

Cons

  • Not scalable
  • Hard to add new types
  • Blocking UI during render
Proposed: Modular (QGIS Style)

Mediator Pattern

  • MapCanvas: Manager/Controller
  • MapLayer: Data + State (Raster/Vector/...)
  • Renderer: Symbology Strategy
  • Job: Async worker

Pros

  • Highly extensible
  • Smooth background rendering
  • Rich symbology support

Question: Focus Area

Should we prioritize extensibility (making it easy to add new layer types like Mesh or WMS) or rendering performance (ensuring 10GB+ rasters pan smoothly) in this first refactor?

A

Priority: Extensibility

Build the abstract base classes for Layers and Providers first.

B

Priority: Performance

Focus on the multi-threaded "Rendering Job" and caching pipeline.
