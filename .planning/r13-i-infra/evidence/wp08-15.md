### 8.2 RED found and fixed — build.sh selftest not executable-file-portable

RED:

```
$ bash scripts/build.sh selftest
selftest FAIL: default jobs = 1: expected '1', got ''            # EACCES on "$0" re-exec
... 8 failures ...
selftest: FAILED                                                 exit 1
```

Root cause: `scripts/build.sh` is mode 100644 in git (same on origin/master); `cmd_selftest` re-executed `"$0"` directly (`scripts/build.sh:166-176,193`), which fails with 权限不够/EACCES on a fresh clone when invoked as `bash scripts/build.sh selftest`.

Fix (minimal, `scripts/build.sh` only): re-exec through `"$BASH" "$0"` in the seven selftest invocations and the spaced/Unicode cwd probe; added a one-line comment recording why.

GREEN ×2:

