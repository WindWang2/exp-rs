# Slices — RS14-17-reproducibility-capsule

Each slice: RED (failing Catch2 cases proving the *missing capability*) → GREEN (minimal implementation) → REFACTOR → narrow test run → commit. Test binary: `tests/test_experiment_capsule.cpp` (one executable, grows per slice; links only Catch2 + Qt6::Core + ExperimentCapsule + experiment + dataset + SQLite).

| Slice | Scope | Key red tests (first cases) |
|---|---|---|
| **A** | `capsule_document.h` value type + `kCapsuleSchemaVersion` + `capsuleDigest` + `canonicalBytes` | digest is stable under QJsonObject key insertion order; digest changes when any section changes; digest section itself excluded from digest; empty/invalid documents rejected by `validateDocument` shape check |
| **B** | `CapsuleBuilder` projections: goal/lab id (labId==experimentId), software, **inputs** (dataset version pins + digests + state), parameters, plan/workflow digest; `CapsuleHooks::capabilityDescriptor` → `capabilities` with content digest | projected parameters equal `run.parameters()`; missing run ⇒ `capsule.run-missing` typed error; capability hook content change ⇒ different capsule digest; unwired capability hook ⇒ entry recorded with `source:"record"`, no fabricated digest |
| **C** | outputs + evidence + provenance: artifacts → `outputs` (portable refs + digests, capped), `EvidenceProjector` summary, verifier hook summary verbatim, lineage slice digest | artifact digest recorded; oversized output ⇒ explicit `external:too-large` state (no silent skip); evidence dimensions mirror `EvidenceProjector::summarize`; verifier hook output embedded verbatim; no hooks ⇒ evidence still complete via store dims, verifier `unknown` never fabricated |
| **D** | `CapsuleIO`: export (canonical bytes, self digest), load (schema gate, digest gate, canonical gate), `validate` (secret scan, absolute-path scan; typed issue codes) | export→load round-trip preserves digest; flipped byte ⇒ `capsule.digest-mismatch`; unknown schema version ⇒ `capsule.schema-unknown`; pretty-printed but semantically identical doc ⇒ `capsule.not-canonical`; planted secret ⇒ `capsule.secret-detected` (fail closed); absolute path in output ref ⇒ `capsule.absolute-path` |
| **E** | `CapsuleReadiness::assess(doc, hooks, datasetStore*)` — replay readiness *from the document*: inputs resolvable? capability descriptor digest still matches? software revision match? outputs present? | all pins resolvable ⇒ Exact; missing dataset version ⇒ Missing + diagnostic string; hook unavailable ⇒ Unknown (never fails closed to Impossible without evidence); digest changed ⇒ Mismatched |
| **F** | `CapsuleDiff::diff(a,b)` — section-typed, identity vs reported, machine-readable | same doc ⇒ Identical; parameters changed ⇒ IdentityBreak naming section; only environment changed ⇒ EquivalentRerun + environment note (ADR 0137); diff report JSON stable/order-independent |
| **G** | Cross-machine portability: build capsule in workspace W1, relocate records under W2 (same content, different absolute paths) ⇒ identical digest; `PortabilityPolicy` edge cases (nested roots, symlinks-out rejected, empty workspaceRoot ⇒ typed error) | relocation ⇒ digest equal; symlink escape ⇒ typed error, never silently accepted; external asset referenced by digest only ⇒ digest equal across machines |
| **W** | Wiring: CLI `capsule export|validate|diff|readiness` (`src/cli/cli_capsule_commands.*`, allowlist arm) with `--json` envelope; `docs/integration.md` agent seam; ADR; exemplar | CLI JSON verdicts semantically equal library verdicts (teaching/agent consistency); `capsule --help` lists subcommands; exemplar capsule file in `examples/` (offline, tiny) |

Commits: one per slice (`feat(capsule): slice A — schema + canonical digest`, …). Planning docs committed first (`docs(capsule): recon/plan/slices for RS14-17`).
