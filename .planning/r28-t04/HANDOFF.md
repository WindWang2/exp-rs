# HANDOFF — R28-T04 (defects owned by other tracks)

## H1 — TaskCenter/JobEngine worker threads render QGIS layouts as fully-transparent images
- **Owner track**: T02 (execution engine / JobEngine thread model) with T03 (worker protocol); discovered + evidenced by T04.
- **Repro**: `test_cartography_production_11` case "engine, operator and agent tool produce byte-identical deliveries", surface 3 (`RSOperator` via `TaskCenter::submitJob` + `waitForTask`). Engine sha `8a0a3a45…`, operator sha `1e3dbc22…`; both PNGs 841×595 with identical chunk layout; operator image mean alpha 0.0 (fully transparent), 99.8 % pixel AE. Engine and agent-tool surfaces (same thread) are byte-identical, so the produce chain itself is deterministic; only the execution thread differs.
- **Mechanism**: `cartography:produce/export/compose` operators call `requireQgisHost()` (cartography_operators.cpp:49) which only checks that a `QgsApplication` exists — not the thread. JobEngine executes operators on detached `std::thread` workers (src/jobs/job_engine.cpp:651-671); QGIS `QgsLayoutExporter` painting off the GUI thread produces a fully transparent image on this host (QT_QPA_PLATFORM=offscreen; X11 behaviour to be re-verified).
- **User impact**: every cartography node submitted through TaskCenter (dock buttons via CartographyDock::submitOperatorJob, workflow pipeline nodes) currently delivers blank/transparent "successful" exports.
- **Suggested acceptance**: a thread-affinity hint on `JobRequest` (or a QGIS-host operator marker) so render-capable operators execute on the GUI thread, or a documented + enforced GUI-thread contract; byte parity then enforced unconditionally in the case above (remove the `SICNU_CP11_THREAD_PARITY` gate). Note: `TaskCenter::waitForTask` parks the main thread on a QWaitCondition without processing events, so a worker-side `BlockingQueuedConnection` marshal back to the GUI thread would deadlock that caller — the affinity must live in dispatch, not in the operator.
- **T04-side interim honesty**: the case enforces the delivery contract (valid PNG, exact page geometry) unconditionally and WARNs the divergence; strict byte parity is opt-in via `SICNU_CP11_THREAD_PARITY=1`.
