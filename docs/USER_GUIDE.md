# 第 1 章：系统概述与快速入门 (System Overview & Quick Start)

## 1.1 软件定位与核心特色

**RS Studio (`exp-rs`)** 是专门面向现代遥感科研、高等院校教学实践以及工业级遥感生产作业构建的新一代桌面地理空间智能分析平台。软件深度融合了 GIS 地理信息系统空间表达能力与遥感（Remote Sensing）全链路图像处理能力，主要具备以下核心技术特色：

- **现代 Ribbon 交互范式**：采用直观高效的 ArcGIS Pro 风格全功能区布局，按遥感工作流逻辑划分为 12 大功能标签页，支持高 DPI 响应式流式布局与全键盘加速。
- **高并发双视口渲染引擎**：基于 QGIS 级高性能地图多视口底座，提供毫秒级多时相/多源数据卷帘（Swipe）、并排联动对比（Comparison）与像素级坐标分辨率同步。
- **7 步向导式遥感分类全流程**：内置从类别定义、多模式 ROI 采集、JM 光谱可分性度量、多算法训练（RF/SVM/Bayes/MLP/SAM）、混淆矩阵评估到分类后处理与多边形化矢量的闭环工作流。
- **面向对象影像分析 (OBIA)**：提供 MeanShift、Watershed、Felzenszwalb 及 OTB 外部多尺度分割引擎，支持构建多层级拓扑树、GLCM 纹理与几何特征计算及对象分类。
- **高光谱与波谱特征工具链**：支持 USGS/ASTER 光谱库检索匹配、连续统去除（Continuum Removal）凸包归一化、端元提取（N-FINDR/VCA）与非负最小二乘（NNLS）线性解混。
- **AI Agent Copilot 智能体协同**：深度集成 LLM 空间感知智能助手，支持自然语言解析遥感意图、自动化 Tool-Calling 调用统一算子、产物自验证（Output Verifier）与故障自愈。

### 1.2.2 响应式工具栏流式条 (Flow Strip)

- **系统就绪指示** (`rsReadyLabel`)：提示当前系统空闲、后台计算任务概要或操作完成耗时。
- **动态地理坐标** (`rsCoordLabel`)：毫秒级跟随鼠标光标，显示当前投影坐标 `X, Y` 或经纬度。

- **当前活动图层** (`rsLayerStatusLabel`)：显示图层树中当前被选中的活动图层名称。
- **图层不透明度滑块** (`rsStatusOpacitySlider`)：0%~100% 实时平滑调节活动图层透明度，方便目视快速透视比对。
- **渲染性能监控** (`rsRenderLabel`)：毫秒 (ms) 级显示视口最近一次重绘所消耗的物理时间。
- **内存缓存占用** (`rsCacheLabel`)：动态统计当前栅格瓦片与金字塔显存/内存缓存占用量（MB）。

## 2.2 多源卫星产品自动化识别与导入

对于成体系的卫星原始数据包，RS Studio 提供了**智能产品探测器 (Product Probe)**，能够自动解析产品级元数据并完成波段分组与物理参数绑定。

```
[选择产品目录 / 压缩包] ➔ [Product Import 自动探测] ➔ [解析元数据 XML/MTL]
                                                         │
       ┌─────────────────────────────────────────────────┼─────────────────────────────────┐
       ▼                                                 ▼                                 ▼
【Landsat 4-9 MTL】                             【Sentinel-2 SAFE】               【MODIS HDF 科学数据集】
• 太阳高度角 / 方位角                             • 10m 分辨率组 (B2,B3,B4,B8)       • 自动提取 Sinusoidal 瓦片网格 (hXXvYY)
• 各波段定标增益/偏置 (Gain/Bias)                 • 20m 分辨率组 (B5,B6,B7,B8A,11,12) • 解析子数据集 (Subdatasets)
• 热红外波段 K1/K2 亮温常数                       • 60m 分辨率组 (B1,B9,B10)         • 读取 Scale Factor 比例缩放因子
• 自动构建多光谱波段栈                            • 自动提取 SCL 场景分类图           • 批量导入地表反射率/植被产品
```

### 2.2.1 Landsat 4-5 TM / 7 ETM+ / 8-9 OLI-TIRS 导入
- **操作入口**：Ribbon「数据」➔「添加栅格」下拉菜单 ➔「**导入 Landsat 产品**」。
- **解析机制**：选择包含 `*_MTL.txt` 的文件夹，探测器自动读取文本元数据：
  - 提取 `RADIOMETRIC_RESCALING` 增益与偏置，用于后续一键无损辐射定标；
  - 提取 `SUN_ELEVATION`（太阳高度角）与 `EARTH_SUN_DISTANCE`（日地距离），用于 TOA 表观反射率校正；
  - 提取热红外波段（如 Landsat 8 的 Band 10/11）的 $K_1, K_2$ 常数用于地表亮温反演。

### 2.2.2 Sentinel-2 MSI (L1C / L2A) 导入
- **操作入口**：Ribbon「数据」➔「**导入 Sentinel-2 产品**」。
- **解析机制**：选择 `.SAFE` 根目录或 `MTD_MSIL*.xml` 元数据文件：
  - **多分辨率智能分组**：自动将影像分解为 10 米组（可见光与近红外 B2, B3, B4, B8）、20 米组（红边与短波红外 B5, B6, B7, B8A, B11, B12）和 60 米组（气溶胶与水汽 B1, B9, B10）；
  - **SCL 场景分类解析**：对于 L2A 级地表反射率产品，自动加载 20 米的 `SCL (Scene Classification Layer)` 波段，为后续自动化云、云阴影与雪掩膜提供数据基础。

### 2.2.3 MODIS (Terra/Aqua) 科学数据集导入
- **操作入口**：Ribbon「数据」➔「**导入 MODIS 产品**」。
- **解析机制**：直接载入 HDF4 数据文件（如 `MOD09GA` 地表反射率、`MOD13Q1` 植被指数等）：
  - 自动展开内部嵌套的子数据集（Subdatasets）列表；
  - 识别正弦投影（Sinusoidal Projection）分幅编号（如 `h26v06`）；
  - 自动绑定各物理波段的 `scale_factor`（如 0.0001）与 `add_offset`，防止用户误将整型 DN 直接用于遥感指数计算。

## 2.3 云端 STAC 目录检索与在线资产加载

RS Studio 内置了符合 OGC STAC (SpatioTemporal Asset Catalog) 规范的云原生空间数据客户端：

```
+-------------------------------------------------------------------------+
```

### 核心管理机制：
1. **全局唯一 Asset ID 与版本控制 (Revision)**：
   - 每个资产分配唯一的 `AssetId`，记录其数据源绝对路径、几何类型、波段物理属性及修改版本号 `Revision`。
2. **独占编辑租约 (Exclusive Edit Lease)**：
   - 当矢量图层开启数字化编辑或被后台算法占用时，系统自动为其下发独占租约（图标显示为 🔒），锁定源文件以防多视口并发写入或读写冲突。编辑提交后，版本号递增并通知所有显示视口重绘。
3. **缺失数据源一键重定位 (Relocate)**：
   - 当工程移动导致文件路径失效时，资产状态显示为 🔴。在资产项上右键选择「**重定位缺失源 (Relocate Source)**」，选择新文件路径后，系统将自动修复工程中所有引用该资产的图层与待执行任务。
4. **提升为持久工程资产 (Promote to Persistent)**：
   - 算法运算生成的临时中间栅格可一键右键「**提升为工程持久资产**」，将其从临时缓存目录归档至工程标准数据目录下。

## 3.5 实时显示拉伸 vs 处理写出拉伸

遥感影像通常具有 16-bit（0~65535）或 32-bit 浮点的高动态范围，直接映射到显示器 8-bit（0~255）时容易出现“全黑”或“对比度极低”的现象。RS Studio 提供了两种拉伸机制：

```
+----------------------------------------------------------------------------------------------------+
|                                    遥感影像对比度拉伸双轨机制                                       |
+--------------------------------------------------+-------------------------------------------------+
|   【显示拉伸】Display Stretch (实时渲染面板)      |   【处理写出拉伸】Contrast Stretch (算法对话框)   |
+--------------------------------------------------+-------------------------------------------------+
| • 纯内存计算，仅更新 QgsRasterRenderer 颜色映射表  | • 通过 GDAL/C++ 遍历物理像素重算矩阵量化值       |
| • 瞬时响应，毫秒级更新视口显示                   | • 生成全新的单波段/多波段 GeoTIFF 文件落盘      |
| • 原始像素数值保持不变 (不破坏 DN 值与光谱物理量) | • 像素数值被永久映射到指定量化区间 (如 0~255)   |
| • 适用于：目视解译、制图浏览、波段比对           | • 适用于：输出制图、深度学习前处理、第三方软件交互 |
+--------------------------------------------------+-------------------------------------------------+
```

### 五大拉伸算法原理与应用场景：

1. **Min-Max (极值全范围线性拉伸)**：
   $$DN_{out} = \frac{DN_{in} - DN_{min}}{DN_{max} - DN_{min}} \times 255$$
   - 将影像实际出现的最小至最大值线性映射到 0~255。如果影像中存在坏像元或极值噪点，拉伸效果会被拉平。
2. **Percentage Clip (百分比截断拉伸，推荐)**：
   - 统计影像直方图累积分布，将两端低百分比（如 2%）和高百分比（如 98%）作为截止极值 $[DN_{2\%}, DN_{98\%}]$，中间区域线性映射，两端分别饱和截断为 0 和 255。
   - **适用**：绝大多数光学遥感影像的目视增强首选，有效抑制异常云点或阴影噪点。
3. **Std Dev (标准差拉伸)**：
   - 基于影像均值 $\mu$ 与标准差 $\sigma$，设定动态范围为 $[\mu - k\sigma, \mu + k\sigma]$（$k$ 通常取 2 或 3）。
   - **适用**：符合正态分布的均匀区域影像，能极大增强典型地物反差。
4. **Histogram Equalization (直方图均衡化)**：
   - 将输入直方图转换为均匀平坦分布，使每个灰度级的像元出现概率大致相等。
   - **适用**：对比度严重偏向暗部或亮部的低照度/雾霾影像，但可能会损失部分细节层次。
5. **Piecewise Linear (分段线性拉伸)**：
   - 在直方图曲线上自定义多个折点控制点 $(x_i, y_i)$，针对特定反射率区间进行有针对性的局部斜率放大。
   - **适用**：水体微弱差异提取或高反射建筑物细节突出。

## 4.2 7 步标准引导流程详述

### Step 0: 类别体系定义 (Class System)
1. **添加地物类别**：点击「添加类别」按钮，系统自动分配递增的整型 `Class ID`（从 1 开始递增，0 预留为未分类/NoData）。
2. **命名与配色**：

3. **模板复用**：支持将类别体系保存为模板文件 (`*.json`)，或一键导入历史土地利用分类标准模板（如 CNLUCC 标准一级/二级分类体系）。

---

### Step 1: 训练与验证样本采集 (ROI Samples)
在分类画布上为每个类别采集代表性样本多边形 (Regions of Interest, ROI)：

```
+-------------------------------------------------------------------------+
| ROI 采集工具条:                                                         |
| [✋ 漫游] [👆 选择] [⬡ 多边形] [▭ 矩形] [• 点] [✏️ 自由画] [🪄 魔棒工具] |
| 样本角色: 🔘 训练样本 (Train Role)   ⚪ 验证样本 (Validation Role)       |
+-------------------------------------------------------------------------+
```

1. **选择激活类别**：在类别列表中高亮选中目标类别（如“水体”）。
2. **选择采集工具**：
   - **添加多边形 (`rsToolSampleAddPolygon`)**：在地图上连续左键点击锚点勾勒图斑，右键或双击结束绘制，系统自动将该多边形打上当前类别的 `cls_id` 标签；
   - **矩形工具 (`rsToolSampleRectangle`)**：按住左键拖拽框选规则水域或农田；
   - **点采样 (`rsToolSamplePoint`)**：在均质均一区域点选典型像元；
   - **魔棒工具 (`rsToolRoiMagicWand`)**：在均质地表点击种子像元，设置光谱容差（Spectral Tolerance，如 15.0），算法自动按四邻域/八邻域区域生长提取同质多边形。
3. **样本角色划分**：
   - 支持通过单选框切换当前采集为 **训练样本 (Train)** 还是 **独立验证样本 (Validation)**；若未单独采集验证集，系统将在训练步骤中按比例（如 70% 训练 / 30% 验证）进行自动分层随机抽样 (Stratified Holdout Split)。
4. **像元充足性校验**：
   - 界面实时汇总每个类别的多边形数量与总像素数。**系统硬性安全阈值要求每个训练类别必须拥有 $\ge 10$ 个有效像元**，否则在进入下一步时会触发阻断警告，确保统计模型参数矩阵可解。

---

### Step 2: 样本光谱特征与 JM 可分性评价 (Separability Evaluation)

在正式训练前，科学评估样本质量可避免盲目训练导致的分类混淆：

```
+------------------------------------------------------------------------------------+
| 类别光谱反射率曲线 (Spectral Curve)       | Jeffries-Matusita (JM) 距离可分性矩阵     |
| 反射率                                    | 类别    | 水体  | 植被  | 建筑  | 裸地     |
| 1.0 │      --- 植被 (NIR波峰)             | 水体    |  -   | 1.99  | 1.98  | 2.00     |
|     │     /                               | 植被    | 1.99 |  -    | 1.85  | 1.92     |
| 0.5 │    /  \                             | 建筑    | 1.98 | 1.85  |  -    | 1.12 ⚠️  |
|     │ --水体 (全波段低吸收)                | 裸地    | 2.00 | 1.92  | 1.12  |  -       |
| 0.0 └──┴──┴──┴──┴──┴──┴──> 波段 (B1~B7)   | [提示: 建筑与裸地 JM 距离=1.12，建议补充特征] |
+------------------------------------------------------------------------------------+
```

1. **类别光谱曲线 (`RsSpectralCurveWidget`)**：
   - 动态绘制各个类别在所有波段上的光谱均值曲线，并附带 $\pm 1\sigma$ 标准差误差棒。若两类别的光谱曲线在所有波段均高度重叠且误差棒交叉，表明仅凭光谱特征难以区分。
2. **JM 距离可分性矩阵 (`RsJmMatrixWidget`)**：
   - 计算任意两类之间的 Jeffries-Matusita (JM) 距离与 Transformed Divergence (TD)：
     $$JM_{ij} = 2 \left( 1 - e^{-\alpha} \right)$$
     其中 $\alpha$ 为 Bhattacharyya 距离：
     $$\alpha = \frac{1}{8}(\mu_i - \mu_j)^T \left( \frac{\Sigma_i + \Sigma_j}{2} \right)^{-1} (\mu_i - \mu_j) + \frac{1}{2}\ln \frac{\det \left( \frac{\Sigma_i + \Sigma_j}{2} \right)}{\sqrt{\det(\Sigma_i)\det(\Sigma_j)}}$$
   - **JM 距离判别标准表**：
     - **$1.90 \sim 2.00$（绿色 - 优秀）**：两类在地物特征空间完全可分，分类精度极高。
     - **$1.00 \sim 1.89$（黄色 - 中等）**：存在一定重叠，建议引入纹理特征、植被指数或高程波段辅助。
     - **$< 1.00$（红色 - 混淆）**：存在严重混淆，需重新审查采集的 ROI 纯度或考虑将两类合并。

---

### Step 3: 特征归一化与机器学习分类推理 (Training & Inference)

1. **特征标准化 (`RsFeatureScaler`)**：
   - **MinMax 缩放**：线性映射到 $[0, 1]$；
   - **Z-Score 正态标准化**：$x' = (x - \mu)/\sigma$，消除不同传感器波段量纲差异；
   - **Robust 稳健缩放**：基于中位数和四分位距 (IQR)，抑制极端异常值。
2. **机器学习分类器算法选型与超参数配置**：
   - **随机森林 (Random Forest / RTrees)**：
     - `决策树颗数 (Trees Count)`：常用 100~300；
     - `最大树深 (Max Depth)`：默认 20；
     - `最小叶节点样本数`：默认 1。高维多光谱分类首选，抗过拟合能力极强。
   - **支持向量机 (SVM)**：
     - `核函数`：RBF (径向基核，默认推荐)、Linear (线性核)、Polynomial (多项式核)；
     - `惩罚系数 C` 与 `核参数 $\gamma$`：支持内置网格搜索自动超参数调优。
   - **正态贝叶斯 (Normal Bayes)**：
     - 基于多元正态分布假设的最大似然贝叶斯估计，计算速度快，适合小样本均质分类。
   - **多层感知机 (ANN_MLP)**：
     - 深度神经网络分类器，支持自定义隐藏层神经元结构（如 `[32, 16]`）与最大迭代轮数。
   - **光谱角度映射 (SAM)** 与 **K-Means 聚类**：
     - 提供高维光谱角分类与无监督聚类对照。
3. **视口快速预览 (Quick Preview)**：
   - 点击「**快速预览**」，算法仅截取当前主视口可见范围内的栅格切片进行毫秒级训练推理并即时渲染，方便在数秒内验证参数有效性。
4. **全图正式分类 (Apply Classification)**：
   - 指定输出 GeoTIFF 路径，点击「**应用分类 (Apply)**」，系统将分类任务提交至后台 Task Center 线程池，采用大矩阵分块流式计算（Block-wise Processing），确保大图分类过程中 UI 丝滑不卡顿。

---

### Step 4: 混淆矩阵与分类精度综合评估 (Accuracy Assessment)

分类完成后，基于独立的验证样本像元计算混淆矩阵（Confusion Matrix / Error Matrix）：

```
+-------------------------------------------------------------------------------------------------+
| 混淆矩阵 (Confusion Matrix)                                                                     |
+-------------------+---------+---------+---------+---------+---------+-----------+---------------+
| 真实 \ 预测       | 水体    | 植被    | 建筑    | 裸地    | 行总计  | 用户精度  | 错分误差(CE)  |
+-------------------+---------+---------+---------+---------+---------+-----------+---------------+
| 水体              |  485    |    0    |    3    |    0    |   488   |  99.38%   |    0.62%      |
| 植被              |    0    |  1240   |   15    |    8    |  1263   |  98.18%   |    1.82%      |
| 建筑              |    2    |   18    |  890    |   35    |   945   |  94.18%   |    5.82%      |
| 裸地              |    0    |    5    |   22    |  610    |   637   |  95.76%   |    4.24%      |
+-------------------+---------+---------+---------+---------+---------+-----------+---------------+
| 列总计            |  487    |  1263   |  930    |  653    |  3333   |           |               |
| 制图精度 (PA)     | 99.59%  | 98.18%  | 95.70%  | 93.42%  |         | **OA: 96.76%**            |
| 漏分误差 (OE)     |  0.41%  |  1.82%  |  4.30%  |  6.58%  |         | **Kappa: 0.9542**         |
+-------------------+---------+---------+---------+---------+---------+-----------+---------------+
```

### 核心评估数学指标：
- **总体精度 (Overall Accuracy, OA)**：
  $$OA = \frac{\sum_{i=1}^k x_{ii}}{N} \times 100\%$$
- **Kappa 一致性系数 (Kappa Coefficient)**：
  $$\hat{K} = \frac{N \sum_{i=1}^k x_{ii} - \sum_{i=1}^k (x_{i+} \cdot x_{+i})}{N^2 - \sum_{i=1}^k (x_{i+} \cdot x_{+i})}$$
  - $\hat{K} > 0.80$ 表示分类结果与真实地面具有极高一致性；$0.60 \sim 0.80$ 为中等一致。
- **制图精度 / 生产者精度 (Producer's Accuracy, 召回率 Recall)**：$PA_i = x_{ii} / x_{+i}$。
- **用户精度 (User's Accuracy, 精确率 Precision)**：$UA_i = x_{ii} / x_{i+}$。
- **F1 分数 (F1-Score)**：$F1_i = 2 \cdot \frac{PA_i \cdot UA_i}{PA_i + UA_i}$。
- **K 折交叉验证 (K-Fold Cross Validation)**：将样本分为 $K$ 份（如 $K=5$）轮番验证，输出平均精度与方差，评估模型泛化能力。
- **导出报表**：支持一键将混淆矩阵与完整精度指标导出为 CSV 表格。

---

### Step 5: 分类后处理与图斑平滑 (Post-Processing)

像元级分类结果常包含因局部像元混合或噪声导致的“椒盐噪点（Salt-and-Pepper Noise）”。后处理提供三大算子：

```
+-----------------------------------------------------------------------------------------------+
|                                    分类后处理平滑与过滤技术                                    |
+------------------------------------+------------------------------------+---------------------+
| 1. 众数滤波 (Majority Filter)       | 2. 碎斑过滤 (Clump & Sieve)        | 3. 类别合并 (Recode)|
| • 采用 3x3 或 5x5 移动窗口          | • 连通域标记 (Clump 8-邻域)        | • 将多个细分小类    |
| • 统计窗口内最高频类别 ID 替换中心像元 | • 过滤像元数 < 阈值的孤立细碎小斑块 |   合并重映射为宏观大类 |
| • 消除孤立噪点，平滑地类边缘       | • 自动吸收合并到相邻面积最大的类别 | • 更新色彩映射表与编号 |
+------------------------------------+------------------------------------+---------------------+
```

1. **众数滤波 (`rs_post_process_task`)**：在对话框中选择窗口半径（1 代表 $3\times3$，2 代表 $5\times5$）。
2. **碎斑过滤 (Clump & Sieve)**：设置「最小图斑像元数 (Min Region Size)」（如 10 像元），低于该阈值的连通图斑将被清除并融合至周围主导图斑。
3. **类别合并与重编码 (Recode / Merge Classes)**：在表格中勾选多个源类别（如“深水”和“浅水”），指定目标类别为“水体”，一键更新分类图。

### Step 6: 成果输出、矢量化与实验报告 (Export & Reporting)

1. **分类成果栅格输出**：导出携带色彩映射表（Color Table）与 GeoTIFF 空间投影的标准单波段分类栅格。
2. **矢量多边形化 (Polygonize to Shapefile/GeoPackage)**：
   - 自动基于 GDAL 矢量化引擎将同质分类像元聚集转换为矢量面要素（Polygon），属性表自动填充 `class_id` 与 `class_name` 字段，便于在 GIS 平台中进行后续拓扑编辑与空间统计。
3. **一键载入主工程**：勾选后直接将分类结果注册为 Data Asset 并自动添加到主地图视口图层栈。
4. **生成实验报告 (Generate Lab Report)**：
   - 系统自动提取输入数据路径、波段配置、样本统计、分类器超参数、混淆矩阵、OA/Kappa 指标及结果缩略图，一键导出为格式规范的 Markdown 实验报告或 PDF 文档。

# 第 5 章：面向对象影像分析 (OBIA - Object-Based Image Analysis)

## 5.1 面向对象分析基本原理

随着高分辨率遥感影像（如 WorldView、高分二号/六号、无人机航测）的普及，“同物异谱”、“同谱异物”现象加剧，传统的像元级分类面临严重的椒盐效应与结构信息丢失。面向对象影像分析 (OBIA) 的核心思想是：**以具有同质物理属性的多边形图斑（对象/Segment）作为基本单元，综合利用对象的光谱、形状、纹理及层级拓扑特征进行分类**。

---

## 5.2 多尺度影像分割算法

在 `RsObiaMainWindow` 窗口中，系统内置了 4 种高性能影像分割算法：

1. **MeanShift (均值漂移分割，推荐)**：
   - **空间半径 (Spatial Radius)**：控制搜索邻域像素范围（常用 5~15）；
   - **范围半径 (Range Radius)**：控制光谱色彩差异容差（常用 10~30）；
   - **最小图斑大小 (Min Region Size)**：过滤微小图斑（如 20 像素）。
2. **Watershed (分水岭分割)**：
   - 基于图像梯度幅值构建地形表面，从局部极小值注水生成封闭汇水盆地，边界定位精确。
3. **Felzenszwalb (基于图的高效分割)**：
   - 基于图论最小生成树的贪心聚类算法，在保持长条状道路、河流等连续地物方面表现优异。
4. **OTB Segmentation (外部高性能引擎)**：
   - 调用 Orfeo ToolBox 算法库，支持对数 GB 级别的超大区域影像进行分块无缝分割。

---

## 5.3 多层级对象拓扑结构 (Object Hierarchy)

RS Studio 支持构建双层乃至多层级的空间对象树：

```
+-------------------------------------------------------------------------------+
|                            多层级对象拓扑树结构                               |
+-------------------------------------------------------------------------------+
```

# 第 6 章：波谱分析与高光谱工具 (Spectral Analysis & Hyperspectral Tools)

## 6.1 交互式光谱剖面图与元数据解析

高光谱遥感（Hyperspectral）具有几十至上百个连续细分波段。RS Studio 提供了专业的波谱探针：

1. **打开光谱剖面面板**：激活右侧「**光谱剖面 (`SpectralProfileWidget`)**」停靠面板。
2. **元数据自动感知**：
   - 载入高光谱影像时，系统自动扫描读取栅格元数据中的 `WAVELENGTH`（波长，单位 nm 或 $\mu m$）和 `FWHM`（半高全宽）；
   - 横坐标自动标定为物理波长刻度（如 $400\text{ nm} \sim 2500\text{ nm}$），而非简单的波段序号。
3. **动态拾取**：在地图视口中点击任意像元，剖面图毫秒级绘制出该像元的全谱反射率连续曲线；支持在图上绘制多边形提取 **区域均值光谱 (ROI Mean Spectrum)** 及标准差包络线。

## 6.2 连续统去除 (Continuum Removal) 凸包归一化

连续统去除（又称凸包归一化）是高光谱矿物识别与植被吸收特征分析的关键技术：

```
反射率                                    归一化反射率 (CR)
1.0 ├───/\─────── 原始光谱曲线             1.0 ├─────────── 外包凸包归一化为1.0
    │  /  \  /\                               │   \   /\
    │ /    \/  \ 吸收谷深度 (Depth)           │    \_/  \ 突出特定特征吸收位置 (如 2200nm)
0.0 └──┴────┴───┴──────> 波长(nm)         0.0 └───┴────┴──────> 波长(nm)
```

- **数学原理**：利用凸多边形算法计算光谱曲线的外包络凸包线 $C(\lambda)$，将原始反射率 $R(\lambda)$ 除以凸包值：
  $$R'_{CR}(\lambda) = \frac{R(\lambda)}{C(\lambda)}$$
- **软件操作**：在 `SpectralProfileWidget` 工具栏中勾选「**连续统去除 (Continuum Removal)**」，曲线立即将背景连续统归一化为 1.0，极大突显出矿物诊断性吸收谷的中心波长位置、吸收深度与吸收对称度。

---

## 6.3 标准光谱库管理与 SAM / SID 匹配算法

系统内置了标准光谱库检索与识别对话框（`SpectralLibraryDialog`）：

1. **光谱库载入**：
   - 支持加载 USGS 矿物/植被/土壤标准波谱库、ASTER 波谱库及用户自定义保存的 JSON 光谱库。
2. **光谱匹配相似度算法**：
   - **光谱角度映射 (Spectral Angle Mapper, SAM)**：
     $$\theta = \arccos \left( \frac{\sum_{i=1}^M t_i r_i}{\sqrt{\sum_{i=1}^M t_i^2} \sqrt{\sum_{i=1}^M r_i^2}} \right)$$
     将像元光谱向量 $\vec{t}$ 与参考光谱向量 $\vec{r}$ 视为 $M$ 维空间向量，计算广义夹角 $\theta$（弧度）。$\theta$ 越接近 0，说明光谱形态越吻合（不受光照强度整体明暗缩放的影响）。
   - **光谱信息散度 (Spectral Information Divergence, SID)**：
     - 将两条光谱归一化为概率分布向量，基于相对熵（Kullback-Leibler 散度）度量差异，散度值越小越相似。
3. **匹配与新光谱入库**：
   - 点击「**匹配 (Match)**」，系统在毫秒内遍历库中数千条标准光谱，按 SAM 夹角升序输出匹配排名表；
   - 点击「**追加到光谱库 (Save to Library)**」，可将画布上提取的未知地物光谱命名并归档入库。

---

## 6.4 混合像元分解 (端元提取与 NNLS 线性解混)

由于中低空间分辨率影像中一个像元往往覆盖多种地物，混合像元分解旨在反演各基本地物（端元 Endmember）所占的面积比例（丰度 Abundance）：

1. **端元自动提取 (`endmember_extraction`)**：
   - **N-FINDR 算法**：在高维单形体特征空间中寻找体积最大的单形体顶点作为纯净端元；
   - **VCA (顶点成分分析法)**：基于正交投影迭代提取极端端元向量。
2. **非负最小二乘线性解混 (`spectral_unmixing`)**：
   - 线性光谱混合模型：$\vec{x} = \sum_{k=1}^P a_k \vec{e}_k + \vec{\epsilon}$；
   - 满足丰度非负性约束 $a_k \ge 0$ 及全约束 $\sum a_k = 1$ (FCLS/NNLS)；
   - 算法输出每个端元对应的 **丰度图 (Abundance Map)** 栅格栈。

---

## 6.5 高光谱 RX 局部异常探测

- **算法原理**：基于 Reed-Xiaoli 异常检测算子，构建局部滑动背景窗口，计算中心像元相对于局部背景协方差矩阵的马氏距离（Mahalanobis Distance）：
  $$RX(\vec{x}) = (\vec{x} - \vec{\mu})^T \Sigma^{-1} (\vec{x} - \vec{\mu})$$
- **应用场景**：在茂密森林或广袤水域中快速搜寻微小人工目标、失事残骸或突发污染源。

# 第 7 章：遥感预处理与图像增强 (Preprocessing & Image Enhancement)

## 7.1 辐射定标与大气校正 (DOS1, DOS2, QUAC)

### 7.1.1 辐射定标 (Radiometric Calibration)
将传感器记录的无量纲灰度值 (DN) 转换为具有物理意义的表观物理量：
- **大气顶辐射亮度 (TOA Radiance, $L_\lambda$)**：$L_\lambda = \text{gain} \times DN + \text{bias}$，单位为 $\text{W}/(\text{m}^2\cdot\text{sr}\cdot\mu\text{m})$；
- **大气表观反射率 (TOA Reflectance, $\rho_\lambda$)**：结合日地距离修正因子 $d$ 与太阳天顶角 $\theta_{SZ}$ 消除太阳照射几何影响；
- **热红外亮温 (Brightness Temperature, $T_b$)**：利用普朗克函数反演开尔文温度 (K)。

### 7.1.2 大气校正 (Atmospheric Correction)
- **DOS1 (暗目标减法 1)**：假设暗像元（深水、深阴影）在地表的理论反射率为 0，其在大气顶测得的微弱信号完全由大气路径散射辐射引起，从全图扣除该常数。
- **DOS2**：在 DOS1 基础上引入大气透过率与气团参数 (Airmass)，校正精度进一步提高。
- **QUAC (快速经验大气校正)**：无需外部气象参数，直接基于整景图像中丰富地物的波谱统计均值进行全局经验拟合，直接输出 $[0, 1]$ 地表反射率。

## 7.3 影像几何配准实战 (I2I 双画布、SIFT 匹配、I2M)

几何配准窗口（`QgsGeoreferencerMainWindow`）支持将未经校正的原始航片/历史影像与标准基准地图对齐：

```
+----------------------------------------------------------------------------------------------------+
| 影像对影像几何配准 (Image-to-Image Georeferencer)                                                    |
+------------------------------------+------------------------------------+--------------------------+
| 待校正源影像画布 (Warp Canvas)     | 参考基准影像画布 (Base Canvas)     | 控制点表与校正参数       |
|                                    |                                    | 控制点: 12 对 (DOF = 6)  |
|      [+ GCP 1]                     |      [+ GCP 1]                     | 变换模型: 多项式 2 阶    |
|                                    |                                    | 重采样: 双线性 (Bilinear)|
|                                    |                                    | **总 RMS 残差: 0.42 像素**|
|  [SIFT 自动匹配] ➔ [RANSAC 粗差剔除]                                    | [🚀 开始校正并加载]      |
+------------------------------------+------------------------------------+--------------------------+
```

1. **配准模式选择**：
   - **Image to Image (I2I)**：左侧打开待配准源图，右侧打开高精度参考基准正射影像；
   - **Image to Map (I2M)**：左侧打开源图，右侧直接在 RS Studio 主工程地图视口中点选拾取地理坐标。
2. **GCP 控制点采集**：
   - **手动交互点选**：按下快捷键 `A` 激活添加控制点工具，在两幅影像明显地物拐角（道路交叉口、桥梁端头、建筑角点）成对点击拾取；
   - **SIFT 自动特征匹配 (`sift_match`)**：点击「SIFT 自动匹配」，系统自动提取尺度不变特征点，利用 RANSAC 算法剔除误匹配点对，秒级生成数十对高精度 GCP。
3. **几何变换模型选择与自由度 (DOF)**：
   - **线性变换 / Helmert**：至少需要 $\ge 2$ 点，支持缩放、旋转和平移；
   - **多项式 1 阶 (Affine 仿射)**：至少需要 $\ge 3$ 点，校正比例尺缩放与剪切形变；
   - **多项式 2 阶**：至少需要 $\ge 6$ 点，校正平原与低山丘陵的二阶非线性畸变；
   - **多项式 3 阶**：至少需要 $\ge 10$ 点，校正高阶复杂非线性形变；
   - **薄板样条函数 (TPS - Thin Plate Spline)**：局部非刚性形变精准拟合（至少 $\ge 4$ 点）；
   - **RPC 物理模型**：基于高分辨率卫星携带的 90 项有理多项式模型，结合外部 DEM 进行精密校正。
4. **残差与 RMS 评估**：
   - 控制点列表实时显示每个点的 $\Delta X, \Delta Y$ 与总体 RMS 均方根误差。若总 RMS $< 1.0$ 像素（高精度生产建议 $< 0.5$ 像素），方可执行校正。

## 7.4 正射纠正与多景影像无缝镶嵌

### 7.4.1 正射纠正 (Orthorectification)

### 7.4.2 影像镶嵌 (Mosaic)

- **色彩平衡 (Color Balance)**：自动进行直方图匹配，彻底消除相邻景之间的曝光色差与缝隙接边。

## 7.5 空间滤波与 SAR 相干斑抑制滤波

### 7.5.1 光学空间卷积滤波 (`SpatialFilterDialog`)

### 7.5.2 SAR 雷达相干斑滤波 (`SpeckleFilterDialog`)
针对合成孔径雷达（SAR）固有的斑点噪声（Speckle Noise），内置自适应统计滤波器：

## 7.6 波段代数运算、光谱指数与影像融合

### 7.6.1 波段运算器 (Band Math)
在 `BandMathDialog` 中输入数学表达式，波段变量采用 `b1, b2, ...`（从 1 开始）：
- 例如自定义 NDVI：`(b5 - b4) / (b5 + b4)`
- 物理量缩放：`b1 * 0.0001`
- 条件表达式与代数变换：支持标准的加减乘除、括号优先级与三角函数。

### 7.6.2 常用光谱指数计算公式速查

| 指数缩写 | 全称 | 推荐计算公式 | 典型取值范围与应用领域 |
|---|---|---|---|
| **NDVI** | 归一化植被指数 | $\frac{NIR - Red}{NIR + Red}$ | $[-1, 1]$；$>0.2$ 表示存在植被，越高代表植被越茂密健康。 |
| **EVI** | 增强型植被指数 | $2.5 \times \frac{NIR - Red}{NIR + 6 Red - 7.5 Blue + 1}$ | 消除高植被覆盖区的 NDVI 饱和现象，抑制气溶胶干扰。 |
| **SAVI** | 土壤调节植被指数 | $\frac{NIR - Red}{NIR + Red + L} (1 + L)$ ($L=0.5$) | 适用于干旱半干旱稀疏植被区，削弱土壤背景反射影响。 |
| **NDWI** | 归一化水体指数 (McFeeters)| $\frac{Green - NIR}{Green + NIR}$ | 提取开阔水体边界，抑制土壤与建筑混淆。 |
| **MNDWI**| 改进型水体指数 (Xu) | $\frac{Green - SWIR1}{Green + SWIR1}$ | **城镇水体提取利器**；极大抑制密集建筑物阴影的误判。 |
| **NDBI** | 归一化建筑指数 | $\frac{SWIR1 - NIR}{SWIR1 + NIR}$ | 提取城市不透水面、混凝土与建筑用地。 |

### 7.6.3 影像全色融合 (Pan-Sharpening)
将高空间分辨率的全色（Panchromatic）单波段与低空间分辨率的多光谱（Multispectral）多波段融合：
- **Brovey 变换**：基于波段比值快速融合；
- **IHS 变换**：将 RGB 转换到强度-色调-饱和度空间，用全色波段替换 I 分量后逆变换；
- **PCA 融合**：主成分变换后用全色波段替换第一主成分 PC1；
- **加权线性融合 (Linear Weighted)**：精细调整全色波段与多光谱波段的权重比例。

# 第 9 章：常见问题排查与诊断 (Troubleshooting & FAQ)

## 9.1 启动、依赖与环境路径排查

### 现象 1：启动时报错 `ErrorCode 3000: GdalError / OtbError` 或外部算法无法运行
- **产生原因**：系统未找到外部 GDAL 或 OTB 可执行程序路径，或安装的版本与系统动态链接库不兼容。
- **排查与解决方法**：
  1. 打开菜单「设置」➔「选项 (Preferences)」；
  2. 在「GDAL Path」中填入系统 GDAL 二进制文件目录（Linux 通常为 `/usr/bin`，Windows 为 `C:\OSGeo4W\bin`）；
  3. 在「OTB Path」中填入 OTB 安装目录（如 `/opt/OTB-8.1.1`）；
  4. 重启软件后再次在处理工具箱中运行算法。

---

## 9.2 数据加载与投影坐标系异常

### 现象 2：加载影像后视口全黑或显示为纯色色块
- **产生原因**：影像为 16-bit 整型或 32-bit 浮点原始物理值，默认未应用拉伸，导致所有像素值压缩在极小灰度区间。
- **排查与解决方法**：
  1. 在 Ribbon「增强」标签页或主工具栏中打开「**显示拉伸 (Display Stretch)**」面板；
  2. 点击「**2% 截断拉伸 (Percentage Clip)**」或「**标准差拉伸 (Std Dev $2\sigma$)**」，影像即可瞬间恢复正常对比度。

### 现象 3：两个图层加载后无法重叠，视口范围异常巨大
- **产生原因**：两个图层的坐标参照系 (CRS) 不一致（例如一个为经纬度 WGS 84 `EPSG:4326`，另一个为米制高斯投影 UTM `EPSG:32649`），且未开启动态投影。
- **排查与解决方法**：
  1. 查看右下角状态栏 CRS 选择器，点击打开「CRS 预设」对话框；
  2. 将工程 CRS 统一设置为米制投影（如对应分带的 UTM 坐标系）；
  3. 系统将自动对栅格/矢量图层启用实时动态重投影 (On-the-Fly Reprojection)。

---

## 9.3 内存溢出与大规模栅格计算优化

### 现象 4：处理数十 GB 超大影像时提示内存不足或软件卡死
- **产生原因**：算法尝试一次性将全图加载至内存矩阵中。
- **排查与解决方法**：
  1. 确保在算法对话框中输出路径填写为磁盘文件路径（而非纯内存临时层）；
  2. 系统底层算子将自动激活分块流式计算（Block Processing），以 $512\times512$ 或 $1024\times1024$ 瓦片循环处理，内存占用恒定在 200MB 以内；
  3. 在右键图层菜单中选择「**构建外部金字塔 (Build Overviews)**」，极大加速大图的缩放浏览。

---

## 9.4 机器学习分类器训练异常与样本不足

### 现象 5：点击训练时弹出警告 `Insufficient training samples`
- **产生原因**：某个地物类别的有效训练像元总数少于 10 个（违反分类器统计矩阵可解性安全阈值）。
- **排查与解决方法**：
  1. 切换到「**样本 (Samples)**」采集步骤；
  2. 在类别列表中检查各个类别的像元统计数；
  3. 使用「添加多边形」或「魔棒工具」为样本不足的类别补画采集区域，确保每类有效像素数 $\ge 10$。

### 现象 6：SVM / MLP 训练失败或报不收敛错误
- **产生原因**：输入波段数据中包含极端离群值、除零异常或未进行特征归一化。
- **排查与解决方法**：
  1. 在分类设置中开启「**特征标准化 (`MinMax` 或 `Z-Score`)**」；
  2. 勾选「**忽略 NoData**」与边缘填充值；
  3. 若数据维度高且各类别方差大，优先选用鲁棒性更强的 **随机森林 (Random Forest)** 分类器。

---

## 9.5 几何配准奇异矩阵与残差超标

### 现象 7：配准计算时提示 `Matrix Inversion / Non-invertible` 或总 RMS 残差过大
- **产生原因**：采集的 GCP 控制点数量少于所选数学变换模型的最少点数要求，或者多个控制点分布在同一直线上（共线退化）。
- **排查与解决方法**：
  1. 核对各模型的最少点数要求：线性/Helmert $\ge 2$ 点，多项式 1 阶 $\ge 3$ 点，多项式 2 阶 $\ge 6$ 点，多项式 3 阶 $\ge 10$ 点，TPS $\ge 4$ 点；
  2. **确保控制点均匀分布在图像的四周边缘与中心区域**，避免扎堆在某一局部；
  3. 在 GCP 表格中按残差排序，右键禁用或微调个别残差过大的粗差点。

---

## 9.6 AI Copilot 连接超时与工具调用失败

### 现象 8：Copilot 发送消息后提示 `Connection Refused / Timeout`
- **产生原因**：本地 Ollama 服务未启动、API Key 失效或网络代理阻止了 API 握手。
- **排查与解决方法**：
  1. 若使用本地模型，请在终端执行 `ollama serve` 或 `ollama list` 确认服务运行正常；
  2. 点击 Copilot 顶部「⚙️ 设置」，在配置窗口中点击「**测试连接**」排查报错状态码；
  3. 若使用第三方网关，核对 Base URL 末尾是否正确包含 `/v1`。
