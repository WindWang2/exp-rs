# Certified Format Support Matrix — Geospatial I/O Foundation 4.0

Generated by the vision in ADR 0130; the authoritative runtime matrix comes from
`FormatRegistry::supportMatrixJson()` (also surfaced by `data doctor` /
`io:doctor`). This page is the human-readable contract.

**Certification levels**

- **Certified** — this repository carries round-trip tests proving the declared
  fidelity (see `tests/test_io_roundtrip_matrix.cpp` and the per-contract suites).
- **Accessible** — the GDAL driver can typically open the format; ExpRS makes *no*
  fidelity claim. Metadata may be lost in conversion; the doctor flags it.
- **Unavailable in build** — a certified/accessible format whose backing driver is
  missing from the running GDAL; capability queries degrade honestly.

"GDAL has a driver" is **not** "ExpRS certified". Never write "all GDAL formats are
supported" — the honest statement is: every GDAL driver *may* be reachable, and only
the certified subset carries fidelity guarantees.

## CRS policy (summary; see `src/geospatial/crs/crs_policy.h`)

1. Source and destination CRS are explicit at every transform boundary.
2. Axis order is declared per transform (`Authority` vs `TraditionalGis`, default
   traditional-GIS). Geotransform/extent coordinates are always traditional-GIS.
3. A dataset without CRS is `MissingCrs` — the layer refuses to guess. The only
   fallback is caller-declared (`CrsPolicy::allowDeclaredFallback`) and is flagged in
   diagnostics as a declared fallback.
4. Coordinate epochs are carried (dynamic datums); ballpark transformations surface
   `ballpark=true` in transform diagnostics instead of passing silently.

## NoData / scale-offset policy (summary)

- Stored value ≠ physical value: `physical = stored * scale + offset`. Nothing applies
  scale/offset implicitly anywhere in the layer (`applyScaleOffset` is the explicit
  seam).
- NoData (including NaN) is part of the write transaction; masks mark only declared
  NoData; undeclared NoData produces no invalid pixels.
- Dtypes are never demoted implicitly (float→byte requires an explicit, warning-level
  decision — the `visualization` COG preset is the only lossy path and is refused for
  scientific/categorical products).
