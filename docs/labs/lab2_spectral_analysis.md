# 实验2：光谱指数与波段运算

## 实验目的
1. 理解遥感影像的光谱特征
2. 掌握常用植被指数的计算方法
3. 学会使用波段运算进行自定义分析

## 实验数据
- `samples_data/landsat_sample.tif` (7波段Landsat-like影像)

## 实验步骤

### 2.1 加载影像
1. 启动 SICNU GEO RS
2. 菜单: File > Add Raster Layer...
3. 选择 `samples_data/landsat_sample.tif`

### 2.2 查看光谱曲线
1. 菜单: View > Identify
2. 在影像上点击不同地物区域
3. 在识别结果面板中查看光谱曲线
4. 观察不同地物的光谱特征:
   - 水体: 各波段反射率低
   - 植被: 红光低、NIR高
   - 城市: 各波段中等反射率
   - 裸土: 随波长增加反射率上升

### 2.3 计算NDVI植被指数
1. 菜单: Raster > Vegetation Index...
2. 选择 "NDVI" 指数
3. 设置波段映射:
   - 红光波段: Band 4
   - 近红外波段: Band 5
4. 设置输出文件路径
5. 点击 "Run"
6. 查看NDVI结果:
   - 值范围: -1 到 1
   - 植被区域: NDVI > 0.3
   - 水体: NDVI < 0
   - 裸土: NDVI ≈ 0

### 2.4 计算其他植被指数
1. 重复上述步骤，计算:
   - **EVI** (增强植被指数): 减少大气和土壤影响
   - **SAVI** (土壤调节植被指数): 适用于稀疏植被
   - **NDWI** (归一化水体指数): 水体提取
   - **NDBI** (归一化建筑指数): 城市区域提取
   - **MNDWI** (改进归一化水体指数): 增强水体

### 2.5 自定义波段运算
1. 菜单: Raster > Band Math...
2. 输入自定义表达式，例如:
   - 波段比值: `b5 / b4` (近红外/红光)
   - 差值: `b5 - b4` (NIR - Red)
   - 复合运算: `(b5 - b4) / (b5 + b4)` (归一化差异)
3. 设置输出文件路径
4. 点击 "Run"
5. 分析运算结果

### 2.6 结果分析
1. 比较不同植被指数的适用性
2. 分析NDVI与植被覆盖度的关系
3. 讨论波段运算在遥感中的应用

## 思考题
1. 为什么NDVI使用红光和近红外波段？
2. EVI相比NDVI有什么优势？
3. 如何利用波段运算提取特定地物？

## 预期结果
- NDVI: 植被区域值高(>0.3)，水体值低(<0)
- NDWI: 水体区域值高，陆地值低
- NDBI: 城市区域值高，植被区域值低
- 波段比值可以增强特定地物的光谱差异
