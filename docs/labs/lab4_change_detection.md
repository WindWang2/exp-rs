# 实验4：变化检测

## 实验目的
1. 理解遥感变化检测的基本原理
2. 掌握常用变化检测方法
3. 学会分析变化检测结果

## 实验数据
- `samples_data/change_before.tif` (变化前影像)
- `samples_data/change_after.tif` (变化后影像)

## 实验步骤

### 4.1 加载数据
1. 启动 SICNU GEO RS
2. 菜单: File > Add Raster Layer... → 选择 `change_before.tif`
3. 菜单: File > Add Raster Layer... → 选择 `change_after.tif`

### 4.2 目视对比
1. 使用影像对比工具:
   - 菜单: View > Compare Layers...
   - 选择左右图层
   - 使用分屏模式对比
   - 使用闪烁模式对比
2. 记录观察到的变化区域

### 4.3 影像差值法
1. 菜单: Raster > Change Detection...
2. 选择方法: **Difference (差值)**
3. 设置输入:
   - 前时相影像: `change_before.tif`
   - 后时相影像: `change_after.tif`
4. 设置输出文件路径
5. 点击 "Run"
6. 分析差值结果:
   - 正值: 反射率增加
   - 负值: 反射率减少
   - 零值: 无变化

### 4.4 归一化差异法
1. 菜单: Raster > Change Detection...
2. 选择方法: **Normalized Difference (归一化差异)**
3. 设置输入和输出
4. 点击 "Run"
5. 分析归一化差异结果:
   - 值范围: -1 到 1
   - 绝对值越大，变化越显著

### 4.5 变化掩膜生成
1. 菜单: Raster > Change Detection...
2. 选择方法: **Change Mask (变化掩膜)**
3. 设置变化阈值 (例如: 0.2)
4. 设置输入和输出
5. 点击 "Run"
6. 分析变化掩膜:
   - 值为1: 发生变化
   - 值为0: 无变化

### 4.6 变化统计
1. 菜单: Raster > Change Detection...
2. 选择方法: **Statistics (统计)**
3. 查看变化统计信息:
   - 变化像元数量
   - 变化百分比
   - 平均变化幅度

### 4.7 结果分析
1. 将变化检测结果叠加到原始影像上
2. 分析变化的空间分布模式
3. 讨论变化的可能原因

## 思考题
1. 差值法和归一化差异法各有什么优缺点？
2. 如何选择合适的变化阈值？
3. 变化检测在实际应用中有哪些用途？

## 预期结果
- 差值法: 直观显示变化方向和幅度
- 归一化差异法: 标准化处理，便于比较
- 变化掩膜: 二值化结果，便于统计
- 变化区域对应影像中的地物变化
