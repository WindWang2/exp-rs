# 实验5：地形分析

## 实验目的
1. 理解数字高程模型(DEM)的概念
2. 掌握坡度、坡向、山体阴影的计算方法
3. 学会利用地形因子进行地貌分析

## 实验数据
- `samples_data/dem_sample.tif` (数字高程模型)

## 实验步骤

### 5.1 加载DEM
1. 启动 SICNU GEO RS
2. 菜单: File > Add Raster Layer... → 选择 `dem_sample.tif`
3. 在图层面板中查看DEM信息:
   - 高程范围
   - 空间分辨率
   - 坐标系统

### 5.2 DEM可视化
1. 右键点击DEM图层 → Properties
2. 切换到 "Symbology" 标签
3. 选择 "Singleband Pseudocolor" 渲染
4. 选择颜色渐变 (例如: 绿-黄-红)
5. 应用并查看彩色DEM

### 5.3 坡度计算
1. 菜单: Raster > Terrain Analysis > Slope / Aspect / Hillshade...
2. 选择输入DEM: `dem_sample.tif`
3. 勾选 "Slope (坡度)"
4. 设置输出文件路径
5. 点击 "Run"
6. 查看坡度结果:
   - 值范围: 0° - 90°
   - 平坦区域: 0°
   - 陡峭区域: > 30°

### 5.4 坡向计算
1. 重复上述步骤
2. 勾选 "Aspect (坡向)"
3. 设置输出文件路径
4. 点击 "Run"
5. 查看坡向结果:
   - 值范围: 0° - 360°
   - 北坡: 0° (360°)
   - 东坡: 90°
   - 南坡: 180°
   - 西坡: 270°

### 5.5 山体阴影
1. 重复上述步骤
2. 勾选 "Hillshade (山体阴影)"
3. 设置光照参数:
   - 太阳方位角: 315° (西北方向)
   - 太阳高度角: 45°
4. 设置输出文件路径
5. 点击 "Run"
6. 查看山体阴影效果

### 5.6 其他地形因子
1. 计算 **地形粗糙度 (Roughness)**: 反映地表起伏程度
2. 计算 **地形起伏度 (TRI)**: 相邻像元高程差
3. 计算 **地形位置指数 (TPI)**: 与周围高程的差异

### 5.7 结果分析
1. 将坡度、坡向、山体阴影叠加显示
2. 分析不同地形因子的空间分布
3. 讨论地形因子在遥感中的应用

## 思考题
1. 坡度和坡向在遥感中有什么应用？
2. 山体阴影的太阳方位角和高度角如何影响效果？
3. 如何利用地形因子进行地貌分类？

## 预期结果
- 坡度: 平坦区域值低，陡峭区域值高
- 坡向: 反映地表的朝向
- 山体阴影: 模拟光照效果，增强地形立体感
- 粗糙度: 反映地表的起伏程度
