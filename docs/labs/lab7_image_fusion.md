# 实验7：影像融合

## 实验目的
1. 理解遥感影像融合的概念和意义
2. 掌握常用影像融合方法
3. 学会评价融合效果

## 实验数据
- 高分辨率全色影像 (可从Landsat获取)
- 低分辨率多光谱影像 (可从Landsat获取)

## 实验步骤

### 7.1 准备数据
1. 获取同一地区的全色影像和多光谱影像
2. 确保两幅影像已配准到同一坐标系

### 7.2 加载数据
1. 启动 SICNU GEO RS
2. 菜单: File > Add Raster Layer... → 加载全色影像
3. 菜单: File > Add Raster Layer... → 加载多光谱影像

### 7.3 Brovey融合
1. 菜单: Raster > Image Fusion...
2. 选择融合方法: **Brovey**
3. 设置输入:
   - 高分辨率影像: 全色影像
   - 多光谱影像: 多光谱影像
4. 设置输出文件路径
5. 点击 "Run"
6. 查看融合结果

### 7.4 PCA融合
1. 菜单: Raster > Image Fusion...
2. 选择融合方法: **PCA**
3. 设置输入和输出
4. 点击 "Run"
5. 查看PCA融合结果

### 7.5 IHS融合
1. 菜单: Raster > Image Fusion...
2. 选择融合方法: **IHS**
3. 设置输入和输出
4. 点击 "Run"
5. 查看IHS融合结果

### 7.6 结果比较
1. 将三种融合结果并排显示
2. 比较空间细节保持程度
3. 比较光谱保真度
4. 计算评价指标:
   - 相关系数
   - 均方根误差
   - 光谱角

### 7.7 结果分析
1. 分析不同融合方法的优缺点
2. 讨论融合在遥感中的应用
3. 总结选择融合方法的原则

## 思考题
1. 为什么需要进行影像融合？
2. Brovey、PCA、IHS融合各有什么特点？
3. 如何评价融合效果的好坏？

## 预期结果
- Brovey融合: 简单快速，但可能改变光谱特征
- PCA融合: 保持光谱特征较好
- IHS融合: 空间细节保持较好
- 融合后影像应同时具有高空间分辨率和多光谱信息
