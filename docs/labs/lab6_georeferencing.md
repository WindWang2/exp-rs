# 实验6：影像配准（几何校正）

## 实验目的
1. 理解遥感影像几何畸变的原因
2. 掌握地面控制点(GCP)的选取方法
3. 学会使用多项式变换进行影像配准

## 实验数据
- 任意未配准的影像 (可使用截图或扫描图)

## 实验步骤

### 6.1 打开几何校正工具
1. 启动 SICNU GEO RS
2. 菜单: Raster > Georeferencer
3. 打开几何校正窗口

### 6.2 加载待校正影像
1. 在几何校正窗口中，菜单: File > Open Raster...
2. 选择待校正的影像文件
3. 影像显示在左侧画布

### 6.3 选取地面控制点(GCP)
1. 在左侧画布上点击明显地物点 (如道路交叉口、建筑物角点)
2. 在右侧画布上对应位置点击相同地物
3. 重复上述步骤，选取至少6个GCP
4. 在GCP表格中查看控制点坐标

### 6.4 设置变换参数
1. 在右侧面板中选择变换方法:
   - **Polynomial 1 (一次多项式)**: 适用于简单变形
   - **Polynomial 2 (二次多项式)**: 适用于中等变形
   - **Polynomial 3 (三次多项式)**: 适用于复杂变形
   - **TPS (薄板样条)**: 适用于局部变形
2. 设置重采样方法:
   - Nearest Neighbor (最近邻)
   - Bilinear (双线性)
   - Cubic (三次卷积)

### 6.5 查看残差
1. 在GCP表格中查看每个点的残差
2. 残差较大的点需要重新选取
3. 目标: 均方根误差(RMSE) < 1像素

### 6.6 执行校正
1. 点击 "Apply" 按钮
2. 设置输出文件路径
3. 等待校正完成
4. 查看校正结果

### 6.7 精度验证
1. 将校正结果加载到主窗口
2. 与参考影像叠加对比
3. 检查几何精度

## 思考题
1. 为什么需要进行影像配准？
2. GCP的数量和分布对校正精度有什么影响？
3. 不同多项式阶数适用于什么情况？

## 预期结果
- GCP残差: 各点残差应小于1像素
- RMSE: 总体均方根误差应小于1像素
- 校正后影像与参考影像几何对齐
