# 实验1：影像增强与空间滤波

## 实验目的
1. 掌握遥感影像对比度增强的基本方法
2. 理解空间滤波的原理和应用
3. 学会使用直方图分析影像特征

## 实验数据
- `data/samples/landsat_sample.tif` (7波段Landsat-like影像)

## 实验步骤

### 1.1 加载影像
1. 启动 SICNU GEO RS
2. 菜单: File > Add Raster Layer...
3. 选择 `data/samples/landsat_sample.tif`
4. 在图层面板中查看影像信息

### 1.2 查看直方图
1. 在图层面板中右键点击影像
2. 选择 "Properties"
3. 切换到 "Histogram" 标签页
4. 观察各波段的直方图分布

### 1.3 对比度拉伸
1. 菜单: Raster > Enhancement > Contrast Stretch...
2. 选择输入图层
3. 选择拉伸方法:
   - **线性拉伸**: 将原始值范围映射到0-255
   - **百分比截断**: 去除两端2%的极值
   - **标准差拉伸**: 以均值±2σ为范围
4. 设置输出文件路径
5. 点击 "Run"
6. 比较不同拉伸方法的效果

### 1.4 直方图均衡化
1. 菜单: Raster > Enhancement > Contrast Stretch...
2. 选择 "Histogram Equalization" 方法
3. 设置输出文件路径
4. 点击 "Run"
5. 观察均衡化后的直方图变化

### 1.5 空间滤波
1. 菜单: Raster > Enhancement > Spatial Filter...
2. 选择输入图层
3. 选择滤波器类型:
   - **均值滤波 (3×3)**: 平滑噪声
   - **高斯滤波**: 加权平滑
   - **中值滤波**: 去除椒盐噪声
   - **Sobel滤波**: 边缘检测
   - **Laplacian滤波**: 边缘增强
4. 设置核大小 (3×3 或 5×5)
5. 设置输出文件路径
6. 点击 "Run"

### 1.6 结果分析
1. 比较原始影像和增强后影像的视觉效果
2. 分析不同滤波器对边缘和噪声的影响
3. 讨论不同增强方法的适用场景

## 思考题
1. 为什么遥感影像通常需要进行对比度增强？
2. 均值滤波和中值滤波在去噪效果上有何不同？
3. Sobel滤波器检测的是什么方向的边缘？

## 预期结果
- 对比度拉伸后，影像细节更加清晰
- 直方图均衡化后，灰度分布更加均匀
- 均值/高斯滤波后，噪声减少但边缘模糊
- 中值滤波后，椒盐噪声被去除
- Sobel/Laplacian滤波后，边缘被增强
