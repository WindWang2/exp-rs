## Data / curriculum

- Manifest: `data/curriculum/undergraduate_rs.curriculum.json`
- Schema: `data/schemas/curriculum.schema.json` (`sicnu.curriculum/1`)
- Modules form a **prerequisite DAG**; catalog Kahn-checks cycles (`cyclic_prerequisites`)
- Lab refs only — no LabSpec body duplication into curriculum
- Roles: `core` | `optional` | `external`; packs via `required_data_packs`
- Teacher notes: objectives / common_mistakes / grading_hook (zh)

## Data / labs & LabSpec versions

- Dual forms coexist: older `*.lab.json` (`spec_version` 1/2) and newer `*.labspec.json` (`sicnu.labspec.v1`)
- Registry maps course ids → source labspec / grading / pipeline / data-spec
- `out_of_scope` labs (e.g. temporal) are external references — curriculum may cite, grading may not own

## Recipes

- Pipeline JSON under `data/labs/pipelines/` is the executable recipe projection
- Console shows compile view read-only; editing LabSpec steps/operators is the authoring path

## Grading / process grader / verifier

- **Artifact path (lab platform):** rules kinds closed enum in schema + `kKnownKinds` in `output_verifier.cpp`
- **Process path (ADR 0174):** `GradingRubric` criteria kinds Stage|Metric|Fact|Answer; fail-closed weight sum / foreign schema / unknown enum
- Missing evidence → indeterminate / not_earned with reasons — **never silent zero**
- Batch: in-process row isolation (`LabBatchRunner`) + process isolation (`run_classroom_batch.py`)

## Lab packs / fixtures / offline

- Packs regenerated by `gen_lab_packs.py` (deterministic); fixtures by `gen_lab_fixtures.py`
- Offline bundle: assemble from build dir, manifest schema `/1` or `/2`, verify via `verify_bundle_manifest.py` (exit 0/1/2)
- Path traversal refused by verifier (`_unsafe_bundle_rel`); console must mirror for pack paths
- Byte ceiling default 250 MB (`--max-mb`)
